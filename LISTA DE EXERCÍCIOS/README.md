# Lista de Exercícios

Esta pasta contém exercícios da disciplina **Programação para Internet**, desenvolvidos com HTML e PHP procedural.

Cada questão possui o frontend separado no arquivo `index.html` e o backend responsável pelo processamento no arquivo `backend.php`.

## Métodos HTTP utilizados

| Questão | Exercício | Método |
|---------|-----------|--------|
| 01 | Cálculo de Desconto em Compra | POST |
| 02 | Classificação de Triângulos | POST |
| 03 | Cálculo de IMC com Categoria | POST |
| 04 | Tabuada Personalizada | GET |
| 05 | Cálculo de Juros Compostos | POST |
| 06 | Estatística de Idades e Alturas | POST |
| 07 | Calculadora de Média e Aprovação | POST |
| 08 | Análise de Faturamento Diário | POST |
| 09 | Tabela de Notas de uma Turma | POST |
| 10 | Soma da Diagonal Principal | POST |

O método GET foi usado na questão 04 porque ela realiza uma consulta simples a partir de um único número. Nas demais questões foi usado POST por haver envio de vários dados ou solicitação de processamento pelo servidor.

## Como executar

Com o Apache iniciado no XAMPP, abra no navegador a pasta de uma questão e acesse seu arquivo `index.html`. Preencha o formulário e envie os dados para ver o resultado gerado pelo `backend.php`.
